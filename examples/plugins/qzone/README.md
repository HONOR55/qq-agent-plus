# QQ 空间 qzone

**让机器人有自己的空间**：想发就发一条说说，也能翻好友动态、点个赞、留句评论。
写出去的每一条都以机器人身份、公开可见 —— 宿主侧按插件限频并逐条记日志。

## 能做什么

- **发说说**：正文（1000 字内）+ 可选配图（最多 9 张）+ 可见范围（公开 / 仅自己 / 指定好友 / 部分可见）
- **看自己**：最近发过什么（tid、正文、时间、评论数、点赞数、自己赞没赞过），发之前查重、删之前核对
  —— 评论数来自空间列表接口，点赞数来自好友动态页；比那一页更旧的说说 `likes` 是 `null`（看不到，不是 0）
- **删自己的**：只能删这个插件最近发过的 20 条，别人的删不掉
- **看好友动态**：作者、正文、时间、图片数、点赞数、评论数
- **点赞 / 评论**：以机器人身份公开互动
- **读评论**：回复之前先看清上下文

## 群里怎么问

- 「发条说说：今天上海的雨停得真快」
- 「你空间里最近发了啥」
- 「把刚才那条说说删了」
- 「看看好友动态，挑一条有意思的评论一下」
- 「给 XX 那条动态点个赞」

## 配置（可选）

```json
{
  "plugins": {
    "settings": {
      "qzone": { "defaultVisibility": 1 }
    }
  }
}
```

- `defaultVisibility` —— 模型没说可见范围时用哪个，默认 `1`（公开）。想默认只给自己看就写 `4`。

## 权限（装之前看一眼）

`capabilities` 里是 **`qzone`**：这是**写**能力，不是只读。

- 发 / 删 / 赞 / 评合计每分钟最多 10 次，其中发说说每小时最多 6 条（宿主侧强制，插件绕不过去）
- 每次写入都写一条 `[plugin:qzone] 空间发布：…` 的日志，控制台查得到
- 正文上限：说说 1000 字、评论 200 字
- **结果未知不重发**：协议端没回 tid 时工具会返回"可能已经发出"，请用 `list_my_moments` 核对；
  Qzone 没有幂等键，重提交就是两条
- 同一条正文 30 分钟内不会重复发（插件自己挡一道）

## 为什么必须由宿主代发

插件进程在 Linux 上被关进没有网络接口的命名空间，也读不到 `config.json` 里的协议端令牌；
而发说说只能走宿主那条 OneBot 连接（SnowLuma 的 `send_qzone_msg`）。所以这个插件调用的是
宿主的 `cap.qzone.*`，**需要宿主 0.9.2 及以上**（`minVersion` 已写明）。

## 装

控制台左侧「插件」→ 安装 → 启用。

手工装（没有 Release 时）：

```bash
# 1) 把本目录拷进数据目录的 plugins/qzone/
mkdir -p "$QQ_AGENT_DATA_DIR/plugins/qzone"
cp -r ./* "$QQ_AGENT_DATA_DIR/plugins/qzone/"
# 2) 在 config.json 的 plugins.enabledIds 里加上 "qzone"，然后重启服务
```

## 边界

- **不会伪造身份**：所有写入都走机器人自己的登录态，没有第二个账号
- **不存凭据**：插件不接触 Cookie / 令牌，状态只有"最近发过什么"
- **删除不能撤销**：删了就没了
- **看不到私密内容**：好友动态只取公开接口给的那一页，翻不了历史、也进不了别人的相册
